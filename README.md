# 팬더의 휴게실 — Three.js 3D 다면체 & 1004gywnd 쇼츠 뮤직

## 파일 구성
- `index.html`: Three.js 3D 다면체 메뉴(팔각 프리즘/정팔면체) + 상/하단 맨위로·맨아래로 링크 + `@1004gywnd` 쇼츠 뮤직 플로팅 플레이어
- `images/`: 메뉴 및 3D 다면체용 실사 이미지 12종
- `vercel.json`: Vercel 정적 배포 설정

## GitHub 업로드 & Vercel 배포
1. GitHub에서 새 저장소(Repository)를 생성합니다.
2. 이 폴더의 파일(`index.html`, `vercel.json`, `images/`)을 저장소에 업로드(또는 `git push`)합니다.
3. [Vercel](https://vercel.com)에서 **Add New → Project**를 클릭하고 해당 GitHub 저장소를 Import합니다.
4. Framework Preset은 `Other` 그대로 두고 **Deploy**를 클릭하면 즉시 배포됩니다.
